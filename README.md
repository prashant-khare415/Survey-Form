# 📝 Survey Form

A simple and clean **Survey Form** built using HTML and CSS.  
This project was created to practice HTML form elements, CSS styling, layouts, and basic user interactions.

---

## 🚀 Live Demo

🔗 **[View Live Survey Form](https://prashant-khare415.github.io/Survey-Form/)**

---

## ✨ Features

- 📝 Name, Email, Age and College fields
- 🎯 Role selection using dropdown
- 💻 Programming language selection using checkboxes
- ✅ Admission preference using radio buttons
- 💬 Feedback textarea
- 🎨 Clean and simple user interface
- ✨ Hover and checked effects
- 📐 Organized form layout

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **Google Fonts**
